# ShopNest 🛍️

A full-stack e-commerce app built with the MERN stack.

🔗 **Live Demo:** https://shopnest-gray.vercel.app

## Features
- JWT authentication (register / login / protected routes)
- Product search & category filters
- Cart & order history
- Admin dashboard

## Tech Stack
| Frontend | Backend | Database |
|---|---|---|
| React + Vite | Node.js + Express | MongoDB + Mongoose |
| React Router | JWT Auth | |
| Deployed on Vercel | Deployed on Render | |

## Setup

**Backend**
```bash
cd backend
npm install
cp .env.example .env   # fill in your values
npm start
```

**Frontend**
```bash
cd frontend
npm install
cp .env.example .env   # fill in your values
npm run dev
```
